このツールについて

「ほどいてみた 投稿係」は、YouTube チャンネル「ほどいてみた」（@hodoitemita）の運営者が、自分で制作した動画を自分のチャンネルへ予約投稿するために、運営者のパソコン上だけで動かしているツールです。一般の利用者向けに提供しているサービスではありません。

使う情報

  • 運営者本人の Google アカウントで許可した、YouTube への動画の投稿権限と、自分のチャンネルの動画一覧を読む権限（YouTube Data API）だけを使います。
  • 扱うデータは、運営者のチャンネル情報と、運営者がアップロードする動画・タイトル・説明文・サムネイル、投稿済みの動画の一覧です。

保存と共有

  • ログイン情報（アクセストークン）と投稿の記録は、運営者のパソコンの中にだけ保存します。サーバーには送りません。
  • Google から受け取った情報を、第三者に販売・共有・譲渡することはありません。広告にも使いません。
  • Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

許可の取り消し

このツールへの許可は、Google アカウントの「サードパーティ アクセス」からいつでも取り消せます。YouTube のデータの扱いについては YouTube 利用規約 と Google プライバシー ポリシー も適用されます。

English summary

"Hodoitemita Uploader" is a private tool run only on the channel owner's own computer to schedule uploads of the owner's own videos to the owner's own YouTube channel (@hodoitemita) via the YouTube Data API. Tokens and upload records are stored locally only, never sold or shared with third parties, and Google user data is used in compliance with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: hodoitemita@gmail.com
